# Contributing

All contributions, bug reports, bug fixes, documentation improvements,
enhancements, and ideas are welcome.

We appreciate your interest in improving this project. This document
outlines how to get involved.

## How to Contribute

1. **Fork** the repository to your own GitHub account.
2. **Clone** your fork locally:
   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   ```
3. **Create a branch** for your change:
   ```bash
   git checkout -b feature/my-improvement
   ```
4. **Make your changes**, following the existing code style.
5. **Commit** with a clear, descriptive message:
   ```bash
   git commit -m "Add: short description of the change"
   ```
6. **Push** your branch to your fork:
   ```bash
   git push origin feature/my-improvement
   ```
7. **Open a Pull Request** against the `main` branch of this repository,
   describing what you changed and why.

## Reporting Bugs

Please open an [Issue](../../issues) describing:
- What you expected to happen
- What actually happened
- Steps to reproduce the problem
- Your environment (OS, Bash version, etc.)

## Code Style

- Keep Bash scripts POSIX-friendly where possible.
- Comment non-obvious logic.
- Test your script locally before submitting a pull request.
