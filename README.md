# Simple Interest Calculator
 
A lightweight, dependency-free Bash CLI tool that computes **simple interest**
from user-supplied **principal**, **rate of interest**, and **time period**.
 
Built as a Git & GitHub practice project to demonstrate proper open-source
repository structure and collaborative workflows — forking, branching,
merging, and pull requests.
 
## Formula
 
```
Simple Interest (SI) = (P × R × T) / 100
```
 
Where `P` = Principal, `R` = Rate of Interest (%), `T` = Time (years).
